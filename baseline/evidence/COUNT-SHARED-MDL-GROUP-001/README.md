# Shared MDL singleton grouping

First bounded singleton-probability grouping experiment on three exposed complete count matrices. Frozen Shared support, spatial graph, tail grouping, conditional odds and tail tables are reused byte-identically. New singleton labels are distinct from the existing tail labels.

See PROTOCOL.md for exact candidate generation, paid model mapping, finite-set selection and predeclared1% practical gate. This is a limited MDL-search codec, not a global optimal clustering algorithm. It does not measure biological entropy or change the integer restoration contract.

No images or neural training are used. Original Shared and all prior experiments remain immutable. Actual candidate streams, fresh decode checks, source pins, encoder search time, failures and reviews will be retained here. Research acceptance depends on raw verification, not this README.
